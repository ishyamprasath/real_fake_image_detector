## Introduction
This project aims to detect AI-generated images. It uses a deep learning model trained on a dataset of real and fake images.

## Installation
Clone the repository:
```bash
git clone https://github.com/ishyamprasath/real_fake_image_detector.git
```

Then, install the dependencies. We recommend using a virtual environment.

```bash
python -m venv venv
source venv/bin/activate   # for Linux/Mac
venv\Scripts\activate      # for Windows
pip install -r requirements.txt
```

## Usage
To use the model, run:
```bash
python predict.py --image_path <path_to_image>
```
